# Accessibility review

The starter uses semantic landmarks, a skip link, explicit form labels, native FAQ disclosure controls, text alternatives to chart values, and visible focus outlines. The workflow diagram supports arrow keys, Home, and End. Playback starts only after interaction and pauses when the page is hidden. Reduced-motion preference disables decorative animation.

Before publishing changes, check:

- Tab through header, links, form fields, diagram controls, and footer in a logical order.
- Submit an invalid form and a demo form; confirm the feedback is announced.
- Use the diagram with arrow keys and without a pointer.
- Review every route at 320px width and 200% zoom.
- Confirm chart labels remain understandable without color.
- Try reduced motion, print preview, and JavaScript disabled.

These are review steps, not a claim of certified conformance. Browser and assistive-technology testing remains necessary for your customized site.
